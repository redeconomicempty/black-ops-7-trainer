## 🧩 About

**Call of Duty Black Ops 7 Companion** is a curated list of Call of Duty Black Ops 7 open-source tools:

- **Overlays** — on-screen helpers, layout notes, hitbox viewer, checkpoint switcher
- **Quality-of-Life Helpers** — loadout catalog, skin manager, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Practice Helpers
- Checkpoint Switcher — practice from any checkpoint
- Show Hitboxes — visualize obstacle hitboxes
- Replay Notes — record and review mission runs
- Playback Speed — adjust playback for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Loadout Catalog — browse weapons, attachments, camos, reticles
- Custom Skin Notes — organize operator cosmetics
- Solid Reticle Trail — improved reticle visibility

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any layout
- Gravity Flip Control — manually switch gravity mid-mission
- Jump Buffer Notes — chain complex maneuvers in the editor
